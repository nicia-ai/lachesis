# Prospective source acquisition

Only the future source-acquirer may receive temporary network egress, and only
after a separate exact materialization authorization. Because exact domains are
not preregistered, candidate domains must be chosen by a frozen prospective
procedure using source class, lawful-use, temporal, robots, and quality rules
that cannot observe outcomes, answers, gold, schedule, or retrieval performance.
The independently reviewed allowlist is digest-frozen before any download.

Requests are bounded GETs with zero retries, strict redirect, content-type,
object-size, campaign-size, and request-count ceilings. Redirects must remain
allowlisted. Active content and archives are rejected. Exact body bytes and
server metadata receive append-only acquisition receipts, including license,
terms, attribution, robots, cutoff, timestamps, and digests.

Offline reconstruction consumes only receipt-ordered retained bytes and the
frozen normalizer. It has no network fallback. The acquisition environment is
destroyed and network removed before construction, materialization, or any study
role starts. This milestone fetched zero URLs.
