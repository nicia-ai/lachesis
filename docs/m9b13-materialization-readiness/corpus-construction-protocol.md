# Fresh clean-room corpus construction

Later construction may use only prospectively admitted, lawfully usable natural
external text. Raw response bytes are retained immutably and identified by
SHA-256 before deterministic text normalization. Normalization may decode,
extract visible text, normalize Unicode and line endings, and remove active or
presentation-only material with a receipt; it may not rewrite meaning.

Documents, chunks, spans, supporting facts, tasks, and citation witnesses use
domain-separated snapshot-bound identities. Hidden answer or abstention
contracts are produced by a separated role. Both arms receive byte-identical,
read-only snapshot sets. Authoring prompts cannot include source solutions,
hidden gold, expected citations, opposite-arm material, cross-packet structure,
or population-wide topology.

Cases must test external knowledge rather than graph-encoded answers. Corpus
layout must not prescribe an optimal sequence; treatment retains a genuine
opportunity to discover useful intermediate values while static retrieval
remains credible. Every read and derived object receives complete provenance.
Uncertain eligibility, lineage, disclosure, or validation quarantines the object
and all descendants; restarting requires a new clean lineage.
