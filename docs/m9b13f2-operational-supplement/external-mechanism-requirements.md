# Future external mechanism requirements

No external registry or mechanism is selected, accessed, or configured by
M9b.13f.2.

Any later submission requires a new immutable external identity; an embargo at
least as restrictive as registration `63sh5` through `2030-08-01T00:00:00Z`; no
public view-only link; no protected metadata or context exposure; exact
immutable attachment hashes; a server submission timestamp; separate approval
where required; independent post-upload byte verification; an append-only local
receipt; and a separate exact submission authorization.

It is prohibited to modify registration `63sh5`, replace or withdraw it, change
or end its embargo, publish it, clone something and present it as the original,
or expose protected context publicly.
