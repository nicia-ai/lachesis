# Frozen population contract

The development suite, 24-pair protocol probe, and 168-pair primary population
have distinct roles. The probe and primary use all eight registered task
families across 1×, 8×, and 32× scale strata: 24 cells, one probe pair and seven
primary pairs in each cell. Scale is canonical NFC document-text UTF-8 bytes,
with inclusive ranges 3,072–5,120, 24,576–40,960, and 98,304–163,840. Scale is a
stratum; same-problem copies across scales are prohibited.

Each paired case presents the same task, snapshot, retriever, model boundary,
retrieval ceiling, answer envelope, and arm-blind evaluator to both arms. The
treatment authors a bounded evidence-adaptive closed retrieval AST; the control
authors one static query. Sessions are independent. Retries and replacements are
zero; maximum concurrency is one.

Development, probe, and primary must be disjoint on every dimension in the
machine contract. The M9b.3f schedule is materialized only after corpus and gold
freeze. All probe cases precede the advancement decision; primary remains
inaccessible unless the frozen gate passes. Outcome-dependent selection,
enrichment, substitution, reordering, or subset analysis is forbidden.

This package contains no future population, case, family, seed, or schedule
identity.
