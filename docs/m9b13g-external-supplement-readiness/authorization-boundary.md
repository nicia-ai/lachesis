# Authorization boundary

M9b.13g authorizes only public documentation research, unauthenticated public
API reads, local append-only readiness artifacts and the requested local
commits.

It grants no authority to access credentials or cookies; authenticate to OSF;
create a draft, project, component, registration, resource or link; upload a
file; submit or approve a registration; publish; change an embargo; modify
registration `63sh5`; materialize any corpus; call a model provider; execute a
study role or analysis; or begin M10.

Draft preparation, one submission attempt, later approval and any local
post-approval receipt are four separately authorized phases. M9b remains NO-GO.
