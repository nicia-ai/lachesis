# Prospective license analysis

OSF Registries does not offer “No License.” OSF says a project-affiliated
license is automatically uploaded when the project is submitted to a
registration, and a user is prompted to select a license at submission when no
project license exists.

Apache License 2.0 is the prospective candidate because all 57 archived files
come from this Apache-2.0 repository. The repository `LICENSE` has raw SHA-256
`1f25afa5f2c0bb79817c2ab472af0db34641cb0a6428219ad7b44e01ee3792ac`. This is a
compatibility rationale, not a new license grant or legal conclusion. Activation
requires confirmation from an authorized rights holder or legal decision-maker.

Current authoritative documentation does not specify the exact filename or bytes
of an automatically uploaded license artifact, nor establish that those bytes
can be inspected during draft staging. If a new artifact first appears at
submission, or its bytes cannot be frozen beforehand, submission remains NO-GO.
