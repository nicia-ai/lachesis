# Nonclaims

This preregistration package makes no claim that:

- token counting is contractually free;
- CodeMode/RLM or static RAG is superior;
- either arm has better model quality or retrieval quality;
- the design demonstrates compositional generalization;
- a natural, probe, primary, or held-out corpus exists or has been evaluated;
- provider, pricing, latency, cost, or campaign behavior has been observed;
- the system is production-ready, secure, compliant, or professionally audited.

The only decision is that an offline package is ready for a separate review and
possible external-registration authorization.
