# M9b.13 immutable bindings

This private readiness package binds the exact receipt commit/tree, the reviewed
M9b.12f source commit/tree, preregistration package and canonical digest,
checksum-manifest digest, and approved OSF registration `63sh5`. The receipt
states `approved`, `embargoed: true`, `public: false`, with embargo end
`2030-08-01T00:00:00Z`.

The binding also names the registered M9b.12f durable quarantine authority,
authenticated opaque observer identity, transactional atomic admission, closed
SQLite sidecar policy, and M9b.4 effect ledger. It grants no effect authority.
