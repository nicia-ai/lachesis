# M9b.12e operational sequence

1. Independently review the checksum-bound M9b.12e package; no later action is
   implied.
2. If separately authorized, register only that exact package and append its
   immutable receipt.
3. Create or fail-closed open the controller-owned local authority.
4. Authenticate the exact opaque principal through the privileged channel
   adapter and issue a unique opaque launch allocation.
5. Pass authenticated presenter context separately from the untrusted proof and
   admission request.
6. Resolve presenter and launch, then recheck presenter, quarantine, proofs,
   allocation, role, session, and one-time consumption inside atomic admission.
7. Commit quarantine or `admission-effect-started` before any role-startup
   effect; persist completed or conservative ambiguous terminal state.
8. On detected or suspected out-of-protocol operator restore, halt the campaign
   and require a new execution identity—never resume normally.
9. Provider dispatch remains forbidden here and requires the existing M9b.4
   durable pre-dispatch ledger under separate authorization.

This package performs none of these future operational steps.
