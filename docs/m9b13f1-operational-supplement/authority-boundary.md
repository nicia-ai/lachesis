# Zero-authority boundary

All current authorities are absent or false: supplement submission and approval;
external registry or OSF access; trusted-session activation; acquisition;
materialization; corpus, gold, or schedule construction; credential, provider,
or model access; study execution; analysis; publication; Git push; embargo
mutation; and M10.

M9b.13e.1–e.3 runtime reuse, import, activation, configuration-only activation,
and evidentiary use are prohibited. This package contains no synthetic positive
admission fixture or effect-capable entry point.
