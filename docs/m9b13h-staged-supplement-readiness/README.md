M9b.13h is an offline, append-only correction to the transport assumptions in
M9b.13g. It preserves M9b.13g byte-for-byte and accepts its NO-GO for the exact
direct-57-file design. It does not alter the signed M9b.13f.2 requirements.

The correction replaces native external folder preservation with one
deterministic local archive containing the accepted 45-file supplement and
12-file signed review receipt. A future private draft would stage only that
archive, its manifest, and its checksum file, then enumerate and bind every
provider-visible artifact before any separate submission decision.

This package creates no OSF draft, project, registration, resource, link, or
authorization. It performs no upload, submission, approval, cancellation,
publication, embargo change, study operation, or M10 work. Registration `63sh5`,
M9b.13f.2, its signed receipt, and M9b.13g remain unchanged.

Current authoritative documentation leaves provider-generated license bytes and
their pre-submission inspectability unresolved. The package therefore freezes a
fail-closed staged design and does not authorize Stage A or Stage B. M9b remains
NO-GO.
