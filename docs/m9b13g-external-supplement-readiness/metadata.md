# Prospective external record metadata

## Title

Lachesis M9 Operational Supplement: Trusted Controlled Host Boundary

## Record relationship and scope

This would be a separate operational supplement to embargoed OSF registration
`63sh5`. It would contain exactly 45 frozen supplement files and 12 signed
review-receipt files under the `supplement/` and `independent-review-receipt/`
namespaces. It changes no scientific or financial field, does not modify
`63sh5`, and grants no operational authority.

The complete exact description and all cryptographic bindings are frozen in
`metadata.json`.
